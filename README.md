## 📖 Overview

This repository contains implementations of fundamental cryptographic algorithms and network security concepts developed during the **Cryptography and Network Security Laboratory** course.

The objective of this repository is to demonstrate the practical implementation of encryption, decryption, hashing, and key exchange algorithms while understanding their working principles, security properties, and real-world applications.

These programs are intended for **educational purposes** and provide hands-on experience with various cryptographic techniques.

---

## 🎯 Objectives

- Understand the fundamentals of cryptography.
- Learn symmetric and asymmetric encryption techniques.
- Implement classical cipher algorithms.
- Study modern encryption algorithms.
- Explore cryptographic hash functions.
- Understand secure key exchange mechanisms.
- Gain practical programming experience in cryptography.

# 🔑 Algorithms Implemented

## Classical Encryption Algorithms

### Caesar Cipher
- Monoalphabetic substitution cipher
- Encryption & Decryption
- Character shifting technique

---

### Substitution Cipher
- Letter substitution encryption
- Fixed substitution mapping
- Basic cryptographic transformation

---

### Hill Cipher
- Matrix-based encryption
- Linear algebra concepts
- Modular arithmetic implementation

---

### XOR Encryption

#### XOR using Character Pointer
- Pointer-based XOR encryption
- Demonstrates bitwise operations

#### XOR with 127
- Simple XOR cipher using key 127
- Reversible encryption process

# 🔒 Symmetric Key Cryptography

## DES (Data Encryption Standard)

Features:

- 64-bit block cipher
- 56-bit secret key
- Feistel network
- Multiple encryption rounds

---

## Rijndael (AES)

Implementation includes:

- Modern symmetric encryption
- Block encryption
- Substitution-Permutation Network
- Strong security architecture

---

## Blowfish

Repository contains multiple Blowfish implementations.

Features:

- Variable key length
- Fast encryption
- Feistel structure
- Symmetric block cipher

# ⚙️ How to Run

Clone the repository

```bash
git clone https://github.com/manish24ts/cryptographyNetworkSecurity.git
```

Move into the repository

```bash
cd cryptographyNetworkSecurity
```

Navigate to the desired algorithm

```bash
cd CaesarCipher
```

Compile

```bash
gcc filename.c -o output
```

Run

```bash
./output
```

For Windows (MinGW)

```bash
gcc filename.c -o output.exe
output.exe
```
